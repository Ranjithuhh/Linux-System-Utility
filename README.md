# 🐧 Linux System Utility

A simple, menu-driven Linux System Utility built using Bash Shell Scripting.
This project automates access to common Linux system information through
an interactive terminal menu.

## 📌 Project Overview

The Linux System Utility provides quick access to essential system
information without requiring users to remember multiple Linux commands.

Users can select an option from the menu to check the current date,
logged-in user, IP address, disk usage, and memory usage.

## ✨ Features

- 📅 **Current Date:** Displays the current date.
- 👤 **Current User:** Displays the username of the currently logged-in user.
- 🌐 **IP Address:** Displays the system's IP addresses.
- 💾 **Disk Usage:** Displays disk space information in a human-readable format.
- 🧠 **Memory Usage:** Displays RAM and swap memory statistics in MB.
- 🚪 **Exit Option:** Allows users to exit the utility safely.
- 🔄 **Interactive Menu:** Continuously displays the menu until the user chooses to exit.

## 🛠️ Technologies Used

- **Bash Shell Scripting**
- **Linux Command Line**
- **Linux System Utilities**
- **WSL (Windows Subsystem for Linux)**

## 📋 Prerequisites

Before running this project, ensure you have:

- A Linux environment or WSL with a Bash shell.
- Basic Linux command-line utilities such as `date`, `whoami`,
  `hostname`, `df`, and `free`.
